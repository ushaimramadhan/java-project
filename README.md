## Cara Menjalankan
Setiap project memiliki foldernya masing-masing. Untuk menjalankan salah satu project (contoh: Kalkulator):

1. Masuk ke folder project:
   ```bash
   cd 01-kalkulator 

2. Compile file Java:
   ```Bash
   javac Kalkulator.java

3. Jalankan program:
   ```Bash
    java Kalkulator

Dibuat sebagai bagian dari latihan rutin untuk menaklukkan Java Backend Development.
