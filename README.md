## Cara Menjalankan
Setiap project memiliki foldernya masing-masing. Untuk menjalankan salah satu project (contoh: Tebak Angka):

1. Masuk ke folder project:
   ```bash
   cd 01-tebak-angka 

2. Compile file Java:
   ```Bash
   javac TebakAngka.java

3. Jalankan program:
   ```Bash
    java TebakAngka

Dibuat sebagai bagian dari latihan rutin untuk menaklukkan Java Backend Development.
